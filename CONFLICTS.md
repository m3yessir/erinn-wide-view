Compared all 493 release paths with the bundled Uiscias v1.65.0 catalog on September 30, 2026. Found 14 variants across eight groups. These are file-path overlaps, not runtime compatibility tests.

This standalone package cannot merge another mod’s region edits. Disable the overlapping mods before installing it, or use Mooncrest’s FOV slider to merge supported combinations. Do not install this standalone file alongside a Mooncrest-generated FOV package, older Wide View releases, or separate indoor/castle/Guild Hall/Crom FOV test files.
